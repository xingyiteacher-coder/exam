題目：括號是否配對
說明：標籤：S3・狀態機・旗標控制
用一個計數變數當作「狀態」：看到 ( 加一、看到 ) 減一，過程中不能變成負數，最後要剛好回到 0。請判斷一串只含 ( 與 ) 的字串是否正確配對。

輸入說明：一行一個只由 ( 與 ) 組成的字串。
輸出說明：若括號完全配對輸出 yes，否則輸出 no。

範例輸入1：(())
範例輸出1：yes
範例輸入2：(()
範例輸出2：no

筆數：5

輸入1_1：(())
輸出1：yes
分數1：20

輸入2_1：(()
輸出2：no
分數2：20

輸入3_1：()()
輸出3：yes
分數3：20

輸入4_1：)(
輸出4：no
分數4：20

輸入5_1：((()))
輸出5：yes
分數5：20

說明：標籤：S3・狀態機・有限狀態機

輸入說明：第一行為起始燈號（R、G 或 Y）；第二行為非負整數步數 S。
輸出說明：一個字母，為最終燈號（R、G 或 Y）。

範例輸入1：
R
1
範例輸出1：G
範例輸入2：
R
3
範例輸出2：R

筆數：5

輸出1：G
分數1：20

輸出2：R
分數2：20

輸入3_2：2
輸出3：R
分數3：20
