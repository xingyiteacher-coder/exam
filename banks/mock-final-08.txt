題目：感冒傳染的教室
說明：標籤：S3・演算法策略・清單走訪
教室座位排成一直線，用 1 表示一開始感冒、0 表示健康。每過一天，感冒同學會把左右緊鄰的同學傳染（以前一天的狀態判斷）。請算出全班都感冒需要幾天；若沒有任何人一開始感冒，則無法傳染，輸出 -1。

輸入說明：一行 0／1（以空白分隔），為每個座位的初始狀態。
輸出說明：一個整數，為全部感冒所需天數；若無法則 -1。

範例輸入1：0 1 0 0 0
範例輸出1：3
範例輸入2：1 0 0 0 1
範例輸出2：2

筆數：5

輸入1_1：0 1 0 0 0
輸出1：3
分數1：20

輸入2_1：1 0 0 0 1
輸出2：2
分數2：20

輸入3_1：0 0 0
輸出3：-1
分數3：20

輸入4_1：1 0 0 0 0
輸出4：4
分數4：20

輸入5_1：0 0 1 0 0
輸出5：2
分數5：20

題目：分組競賽的隊伍
說明：標籤：S4・演算法策略・貪婪
大隊接力要把 2K 位選手兩兩配成 K 組，希望「實力最強的一組」盡量不要太強（讓比賽公平）。做法是排序後把最弱與最強配、次弱與次強配…請輸出在此策略下，最強一組的兩人實力和。

輸入說明：第一行偶數 N；第二行 N 個整數，為各選手的實力值。
輸出說明：一個整數，為最小化後最強一組的實力和。

範例輸入1：
4
1 2 3 4
範例輸出1：5
範例輸入2：
6
1 2 3 4 5 6
範例輸出2：7

筆數：5

輸入1_1：4
輸入1_2：1 2 3 4
輸出1：5
分數1：20

輸入2_1：6
輸入2_2：1 2 3 4 5 6
輸出2：7
分數2：20

輸入3_1：2
輸入3_2：10 20
輸出3：30
分數3：20

輸入4_1：4
輸入4_2：1 1 1 1
輸出4：2
分數4：20

輸入5_1：6
輸入5_2：3 5 2 8 1 9
輸出5：10
分數5：20

輸入說明：第一行兩個整數 r c；接下來 r 行，每行 c 個非負整數，為各格過路費。

題目：消息能傳到幾人
說明：標籤：S4・圖論・DFS
一則消息從 1 號同學發出，只能沿著「單向」的轉發關係往外傳（u→v 表示 u 會轉給 v）。請算出包含 1 號在內，最後總共有幾位同學收到這則消息。

輸入說明：第一行兩個整數 N M；接下來 M 行，每行兩個整數 u v，表示 u 會轉給 v。
輸出說明：一個整數，為收到消息的人數。

範例輸入1：
4 3
1 2
2 3
3 4
範例輸出1：4
範例輸入2：
4 2
1 2
3 4
範例輸出2：2

筆數：5

輸入1_2：1 2
輸入1_3：2 3
輸入1_4：3 4
輸出1：4
分數1：20

輸入2_2：1 2
輸入2_3：3 4
輸出2：2
分數2：20

輸入3_1：1 0
輸出3：1
分數3：20

題目：二進位裡的燈號
說明：標籤：S3・數值運算・進位轉換
一排燈號用一個十進位數字編碼，把它換成二進位後，每個 1 代表一盞亮著的燈。請算出這個數字對應的二進位表示中，一共有幾盞燈亮著（二進位裡有幾個 1）。

輸入說明：一行一個非負整數 n（0 ≤ n ≤ 10^9）。
輸出說明：一個整數，為二進位中 1 的個數。

範例輸入1：7
範例輸出1：3
範例輸入2：8
範例輸出2：1

筆數：5

輸入1_1：7
輸出1：3
分數1：20

輸入2_1：8
輸出2：1
分數2：20

輸入3_1：255
輸出3：8
分數3：20

輸入4_1：0
輸出4：0
分數4：20

輸入5_1：1023
輸出5：10
分數5：20
