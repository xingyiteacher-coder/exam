題目：路口號誌與車流
說明：標籤：S4・資料結構・佇列(清單模擬)
十字路口每分鐘綠燈最多能放行 k 輛車，放不完的車就排隊等下一分鐘。已知接下來每分鐘各有多少輛車抵達路口，請算出所有時間結束後，路口還有幾輛車在排隊（假設每分鐘先抵達再放行）。

輸入說明：第一行放行量 k；第二行分鐘數 N；第三行 N 個非負整數，為每分鐘抵達的車輛數。
輸出說明：一個整數，為最後仍在排隊的車輛數。

範例輸入1：
3
4
5 1 2 4
範例輸出1：1
範例輸入2：
2
3
0 0 0
範例輸出2：0

筆數：5

輸入1_1：3
輸入1_2：4
輸入1_3：5 1 2 4
輸出1：1
分數1：20

輸入2_1：2
輸入2_2：3
輸入2_3：0 0 0
輸出2：0
分數2：20

輸入3_1：1
輸入3_2：5
輸入3_3：2 2 2 2 2
輸出3：5
分數3：20

輸入4_1：10
輸入4_2：3
輸入4_3：3 3 3
輸出4：0
分數4：20

輸入5_1：2
輸入5_2：4
輸入5_3：5 0 0 0
輸出5：0
分數5：20

題目：最近的逃生門
說明：標籤：S4・圖論・BFS
火災演練時，大樓平面圖中 . 是走道、# 是牆、E 是逃生門（可能有多個）、S 是你的位置。每步走上下左右一格，請算出你到「最近的逃生門」需要幾步；若走不到任何逃生門則輸出 -1。

輸入說明：第一行兩個整數 r c；接下來 r 行，每行長度 c 的平面圖字串（含一個 S，E 可能多個）。
輸出說明：一個整數，為到最近逃生門的步數或 -1。

範例輸入1：
3 3
S..
...
..E
範例輸出1：4
範例輸入2：
3 3
E.S
.#.
..E
範例輸出2：2

筆數：5

輸入1_1：3 3
輸入1_2：S..
輸入1_3：...
輸入1_4：..E
輸出1：4
分數1：20

輸入2_1：3 3
輸入2_2：E.S
輸入2_3：.#.
輸入2_4：..E
輸出2：2
分數2：20

輸入3_2：S..E
輸出3：3
分數3：20

輸入4_1：3 3
輸入4_2：S#E

輸入4_4：..E
