題目：累加到超過門檻
說明：標籤：S1・迴圈・條件迴圈
從 0 開始，每次加上固定的 step，直到總和「超過」門檻 t 為止。請用 while 迴圈計算一共加了幾次。

輸入說明：共兩行：第一行門檻 t、第二行每次增加量 step（皆為正整數）。
輸出說明：一個整數，為加到超過 t 所需的次數。

範例輸入1：
10
3
範例輸出1：4
範例輸入2：
100
10
範例輸出2：11

筆數：5

輸入1_1：10
輸入1_2：3
輸出1：4
分數1：20

輸入2_1：100
輸入2_2：10
輸出2：11
分數2：20

輸入3_1：5
輸入3_2：5
輸出3：2
分數3：20

輸入4_1：7
輸入4_2：2
輸出4：4
分數4：20

輸入5_1：1
輸入5_2：1
輸出5：2
分數5：20

題目：對半到 1 的步數
說明：標籤：S1・迴圈・條件迴圈
一個正整數每次整除以 2（無條件捨去），請用 while 迴圈算出要幾步才會變成 1。

輸入說明：一行一個正整數 n（1 ≤ n ≤ 10^9）。
輸出說明：一個整數，為變成 1 所需的步數。

範例輸入1：8
範例輸出1：3
範例輸入2：1
範例輸出2：0

筆數：5

輸入1_1：8
輸出1：3
分數1：20

輸入2_1：1
輸出2：0
分數2：20

輸入3_1：1000
輸出3：9
分數3：20

輸入4_1：7
輸出4：2
分數4：20

輸入5_1：1024
輸出5：10
分數5：20

題目：第一個平方超過 N
說明：標籤：S1・迴圈・條件迴圈
請用 while 迴圈，從 1 開始逐一測試，找出第一個「平方大於 N」的正整數並輸出。

輸入說明：一行一個非負整數 N。
輸出說明：一個整數，為最小的、平方大於 N 的正整數。

範例輸入1：10
範例輸出1：4
範例輸入2：16
範例輸出2：5

筆數：5

輸入1_1：10
輸出1：4
分數1：20

輸入2_1：16
輸出2：5
分數2：20

輸入3_1：0
輸出3：1
分數3：20

輸入4_1：99
輸出4：10
分數4：20

輸入5_1：1000000
輸出5：1001
分數5：20

題目：讀到 0 為止求和
說明：標籤：S1・迴圈・條件迴圈
會依序讀入若干個整數，讀到 0 就立刻停止（0 不算）。請用 break 中斷迴圈，輸出 0 之前所有數字的總和。

輸入說明：若干行，每行一個整數；保證會出現一個 0 作為結束。
輸出說明：一個整數，為 0 之前所有數字的總和。

範例輸入1：
3
5
0
範例輸出1：8
範例輸入2：
10
20
30
0
範例輸出2：60

筆數：5

輸入1_1：3
輸入1_2：5
輸入1_3：0
輸出1：8
分數1：20

輸入2_1：10
輸入2_2：20
輸入2_3：30
輸入2_4：0
輸出2：60
分數2：20

輸入3_1：0
輸出3：0
分數3：20

輸入4_1：-1
輸入4_2：-2
輸入4_3：5
輸入4_4：0
輸出4：2
分數4：20

輸入5_1：100
輸入5_2：0
輸入5_3：999
輸出5：100
分數5：20

題目：冰雹數列步數
說明：標籤：S1・迴圈・條件迴圈
冰雹數列規則：偶數就除以 2，奇數就乘 3 加 1，反覆進行直到變成 1。請用 while 迴圈算出需要幾步。

輸入說明：一行一個正整數 n（1 ≤ n ≤ 100000）。
輸出說明：一個整數，為變成 1 所需的步數。

範例輸入1：6
範例輸出1：8
範例輸入2：1
範例輸出2：0

筆數：5

輸入1_1：6
輸出1：8
分數1：20

輸入2_1：1
輸出2：0
分數2：20

輸入3_1：7
輸出3：16
分數3：20

輸入4_1：27
輸出4：111
分數4：20

輸入5_1：16
輸出5：4
分數5：20
